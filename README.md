# loans

A single-page loan calculator web app — monthly payments, total interest, payoff
date and a full amortization schedule for any fixed-rate loan (mortgages, auto,
personal).

## Run it

Open `index.html` in any browser, or visit the GitHub Pages site:

**https://kzdanko.github.io/loans/**

No build step, no dependencies, no sign-in. One self-contained HTML file, so it
works offline once loaded.

## Features

- Monthly payment from the standard amortization formula
- Total interest / total paid / payoff date
- Principal-vs-interest donut chart
- Extra monthly payments applied to principal, with interest saved & months-early payoff
- Monthly or yearly amortization schedule
- CSV download of the full schedule
- Loan presets: 30-yr mortgage, 15-yr mortgage, 5-yr auto, 3-yr personal

## Deploy

Served with GitHub Pages from the `main` branch (root). Any push to `main`
redeploys automatically.
